# Expense Tracker

A simple application to log, view, and manage daily income and expenses.

## Features
* **Add Transactions:** Log new expenses and income with a title, amount, category, and date.
* **Delete Entries:** Remove unwanted or mistaken transactions.
* **Balance Summary:** Automatically calculates total income, total expenses, and current balance.
* **Data Persistence:** Saves your records locally so your data stays intact on reload.

## Tech Stack
* **Frontend:** HTML, CSS, JavaScript *(or replace with Python, React, etc.)*
* **Storage:** LocalStorage *(or SQLite, JSON, etc.)*

## Getting Started

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the project folder:
   ```bash
   cd expense-tracker
   ```

### Usage
Open `index.html` in your web browser to start tracking your expenses. 
*(If using Python/Node, replace this with `python app.py` or `npm start`)*
